## 0.1.0

- Initial release of `fluid_ui` engine.
- Added `AdaptiveScaffold` for hybrid navigation.
- Added `AdaptiveRow` and `AdaptiveGrid` for fluid layouts.
- Added `AdaptiveTable` with mobile card conversion.
- Added `AdaptiveText` with fluid typography support.
- Added `FluidPriority` for semantic rendering.
- Added `OverflowRecovery` experimental engine.
- Defined `FluidBreakpoints` and `FluidSpacing` tokens.
